# FPGA Digital Clock ⏱️

A 24-hour digital clock implemented using **Verilog HDL** for FPGA-based digital system design.

The project demonstrates RTL design, clock division, BCD counters, seven-segment display interfacing, and simulation using a Verilog testbench.
